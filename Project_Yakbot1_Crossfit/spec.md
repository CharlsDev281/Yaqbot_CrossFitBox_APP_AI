# Spec

1. To create successfully four pages, teacher, student, sign in and home page. Home page will be the basis and the first one.


2. To put good decoration related with CrossFit Box in the home page, a little bit of the other pages also.

3. To create the button and the events to navigate from home page to sign in clicking the teacher button. Navigate of the sign in to the teacher page clicking sign in and fitting the information into the fields, this information has to fit with the memory of that page (only user and password). If not successful, then the page refreshes with empty fields.

4. To access the students page clicking the button from the home page. There initially it would be decorated well but with a message saying: "waiting for the teachers instructions". When the teacher clicks the button automated and has exercises selected, then the counter will begin and will end until the last exercise. If the teacher clicked manual then the counter will begin and will end in every exercise. The student page will only display the exercise he or she is doing and the timer with initial time. This initial time is associated to the exercise.
